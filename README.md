# Анализ графа
Приложение предназначено для анализа структуры графа зависимостей научных публикаций.

##  Описание

Программа позволяет загружать граф из текстового файла, выполнять обходы (BFS/DFS), искать кратчайшие взвешенные пути (Дейкстра), выявлять критические узлы сети (точки сочленения) и строить минимальное остовное дерево.

**Предметная область:**
*   **Вершины:** Научные статьи (например, `LeCun_1989`, `Vaswani_2017`).
*   **Рёбра:** Факты цитирования или совместного авторства.
*   **Вес ребра:** Условная «сила связи» (частота цитирования, количество соавторов).

**Ключевые функции:**
1.  Поиск кратчайшей цепочки цитирования между двумя работами.
2.  Выявление изолированных областей знаний (компоненты связности).
3.  Определение ключевых статей (точек сочленения), удаление которых разрывает научную сеть.
4.  Построение «скелета» научной области с минимальными затратами на связи (МОД).

##  Алгоритмы

### 1. Обход графа 
| Алгоритм | Описание | Сложность | Применение |
| :--- | :--- | :--- | :--- |
| **BFS** | Послойный обход с использованием очереди `Queue<T>`. | $O(V + E)$ | Поиск компонент связности, проверка достижимости. |
| **DFS** | Рекурсивный обход "вглубь" ветви. | $O(V + E)$ | Полный перебор структуры, поиск циклов. |

### 2. Кратчайшие пути 
*   **Алгоритм Дейкстры:** Поиск кратчайшего пути во взвешенном графе с неотрицательными весами.
    *   *Реализация:* Линейный поиск минимума (без сторонних библиотек приоритетных очередей).
    *   *Сложность:* $O(V^2)$
    *   *Функционал:* Вывод таблицы расстояний и восстановление конкретного маршрута.

### 3. Структурный анализ
*   **Точки сочленения (Articulation Points):** Модифицированный DFS с массивами `disc` и `low` (алгоритм Тарьяна).
    *   *Сложность:* $O(V + E)$
    *   *Цель:* Выявить статьи, критичные для целостности сети.
*   **Минимальное остовное дерево (МОД):** Алгоритм Прима.
    *   *Сложность:* $O(V^2)$ (в текущей реализации через список смежности).

## Формат входных данных

Приложение принимает файлы `.txt` или `.csv`. Каждая строка описывает ребро.
## Запуск приложения
1. Клонируйте репозиторий
2. Откройте файл GraphProject.sln в Visual Studio 2022 (или выше).
3. Убедитесь, что установлен .NET SDK 8.0.
4. Выполните сборку
5. Нажмите F5 для запуска.
6. В интерфейсе нажмите кнопку «Загрузить граф» и выберите файл articles.txt (лежит в папке проекта).
Используйте кнопки меню для выполнения алгоритмов. Результаты и время выполнения отображаются в текстовом поле.
